# rocjitsu: ROCm&trade; Just-in-Time Suite

rocjitsu is a set of simulation, virtualization, and instrumentation tools for ROCm&trade; AMD GPU
applications.

## Supported architectures

| Architecture | ISA | Status |
|---|---|---|
| CDNA3&trade; (gfx94x) | GFX9 | Experimental |
| CDNA4&trade; (gfx950) | GFX9 | Experimental |
| RISC-V RV32I/RV64I | RV32IMAFDC | Experimental |

## Features

- **AMD GPU ISA Execution** - decodes and runs actual GPU machine code
  (HSA code objects extracted from HIP fat binaries compiled by `hipcc`/`amdclang++`).
- **RISC-V ISA Execution** - decodes and runs RISC-V machine code (RV32IMAFDC).
- **Code Object Loading** - loads x86 HIP fat binaries (`Executable`), extracts
  embedded Clang offload bundles, and parses individual AMD GPU HSA device ELFs
  (`AmdGpuCodeObject`). Also supports standalone device ELFs.
- **Basic Block Analysis** - constructs control-flow basic blocks from decoded
  instruction streams, splitting on branches and program terminators.
- **Simulation Engine** - event-driven Parallel Discrete Event Simulation (PDES) framework
  (`lib/simdojo/`) supporting functional and cycle-accurate execution modes with
  conservative Chandy-Misra-Bryant synchronization for multi-threaded simulation.
- **ISA Code Generation** - instruction decoders and execution bodies are
  generated from the [Machine-Readable ISA (MR ISA)](https://gpuopen.com/machine-readable-isa/) XML
  spec via a Python library (`amdisa`).
- **GUI** - optional topology visualizer and timeline viewer.
- **Configuration** - JSON configs validated against FlatBuffers schemas for
  topology, programs, and simulation parameters.
- **Public C API** - stable `rj_*` C API (`rj_code_*`, `rj_vm_*`) with reference-counted
  opaque handles.

## Project layout

```
lib/
  util/                 Header-only shared utilities
    include/util/       bitfield, data types, intrusive list, etc.
  simdojo/              Simulation engine library (namespace: simdojo)
    include/simdojo/    Public headers (components, topology, PDES)
    src/                Implementation files
    DESIGN.md           Architecture and design documentation
  rocjitsu/             Main project library
    include/rocjitsu/   Public C API headers (code/rj_code.h, vm/rj_vm.h, base/rj_status.h)
    src/rocjitsu/       Private headers and sources
      code/             Executable loader, code object, basic block analysis
      config/           JSON/FlatBuffers config loading and checkpointing
      isa/              ISA framework (decoder, instruction, operand)
        arch/amdgpu/    AMDGPU ISA (CDNA3/CDNA4, mostly autogenerated)
        arch/risc_v/    RISC-V ISA (RV32IMAFDC)
      vm/               Virtual machine layer
        amdgpu/         AMD GPU hardware model (CU, SE, XCD, caches, pipelines)
        risc_v/         RISC-V hart model
lib/python/amdisa/      ISA code generation toolchain
schemas/                FlatBuffers schemas (simulation_config, checkpoint)
configs/                Example JSON configurations
tools/
  simgui/               Optional simulation GUI
tests/                  Google Test suite
  kernels/              HIP device kernels for integration testing
```

## Prerequisites

- CMake 3.28+
- C++20 compiler (GCC 12+, Clang 16+)
- Python 3.10+ (for ISA code generation only)
- OpenGL (optional, for the GUI - auto-detected)
- ROCm&trade; toolchain (optional, for compiling HIP test kernels)

Third-party dependencies (Google Test, FlatBuffers, GLFW, Dear ImGui, imnodes,
ImPlot) are fetched automatically via CMake `FetchContent`.

## Building

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

To disable the GUI (removes the OpenGL dependency):

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release -DROCJITSU_BUILD_GUI=OFF
```

## Running tests

```bash
ctest --test-dir build
# or directly:
./build/rocjitsu_tests
```

## Regenerating ISA files

The instruction files (e.g., CDNA4&trade;) under `lib/rocjitsu/src/rocjitsu/isa/arch/amdgpu/cdna4/`
are autogenerated from the MR ISA XML specification. To regenerate:

```bash
python -m amdisa --gen-all \
  -o lib/rocjitsu/src/rocjitsu/isa/arch/amdgpu \
  path/to/amdgpu_isa_cdna4.xml
bash scripts/clang_format.sh
```

Hand-written files (`isa.h`, `insts.h`, `mfma_exec.h`, `addr_calc.h/.cpp`) are
not overwritten by the generator.

## Usage examples

### Run a simulation

```c
#include <rocjitsu/rocjitsu.h>

rj_vm_t *vm = NULL;
rj_vm_create("configs/amdgpu_cdna4.json",
             "schemas/simulation_config.fbs", &vm);

uint64_t ticks = 0;
rj_vm_run(vm, &ticks);

rj_vm_destroy(vm);
```

### Load and inspect a code object

```c
#include <rocjitsu/rocjitsu.h>

rj_code_executable_t *exec = NULL;
rj_code_executable_create("kernels/matmul_naive.o", &exec);

rj_code_object_t *obj = NULL;
rj_code_executable_get_code_object(exec, ROCJITSU_CODE_TARGET_GFX942, 0, &obj);

rj_code_basic_block_list_t *bbs = NULL;
rj_code_basic_block_list_create(obj, ROCJITSU_CODE_TARGET_GFX942, &bbs);

uint32_t num_blocks = rj_code_basic_block_list_size(bbs);
for (uint32_t i = 0; i < num_blocks; ++i) {
    rj_code_basic_block_t *bb = NULL;
    rj_code_basic_block_list_get(bbs, i, &bb);

    for (const rj_code_inst_t *inst = rj_code_basic_block_first_inst(bb);
         inst != NULL; inst = rj_code_inst_next(inst)) {
        char buf[256];
        rj_code_inst_disassemble(inst, buf, sizeof(buf));
        printf("%s\n", buf);
    }

    rj_code_basic_block_release(bb);
}

rj_code_basic_block_list_destroy(bbs);
rj_code_object_release(obj);
rj_code_executable_destroy(exec);
```
